# SnapFun Resource System - Final Defense Cue Cards
**Duration: 15 Minutes Maximum**
**Format: Point-by-Point Discussion Prompts**

---

## A. Log In & Registration (1.5 minutes)

**[Screen: Login Page]**

- Introduce SnapFun Resource System
- Two access portals: Regular User + Admin User
- Security through role separation
- New users must register first
- Admin registration requires unique company code (security measure)
- Demo: Admin registration with company code
- Login process with credentials
- System routes to appropriate dashboard based on role

---

## B. Dashboard (1.5 minutes)

**[Screen: Dashboard after login]**

- Dashboard = command center
- Real-time KPIs: revenue, events, inventory, activities
- Strategic view vs. operational detail
- Vital for: immediate visibility, faster decisions, no digging through menus
- AI cards: Stock & Demand Predictor, Financial Insights & Recommendations
- Not static reports - intelligent, data-driven insights
- Transforms raw data into actionable business intelligence

---

## C. AI SnapFunny (2 minutes)

**[Screen: Dashboard, then SnapFunny chatbot]**

- SnapFunny = AI-powered business advisor
- More than chatbot - understands operation
- Capabilities:
  - Answer data questions
  - Provide predictions
  - Generate custom reports
- Example queries:
  - "Predict stock for next 30 days"
  - "Which items need restocking now?"
- Analyzes: inventory levels, upcoming events, historical patterns
- Dashboard AI modules:
  - **Stock & Demand Predictor**: inventory + events + history → forecast demand, alert shortages
  - **Financial Insights**: revenue trends, customer segments, procurement costs → optimization recommendations
- Transforms system from data management to intelligent business partner

---

## D. Assets (2 minutes)

**[Screen: Assets menu]**

- Assets = physical equipment backbone (cameras, lighting, computers, props)
- Significant investment protection
- Demo: Add new asset
- **Generate QR Barcode** (optional but recommended)
  - Unique QR per asset
  - Print + attach to physical equipment
  - Enables scanning/tracking
- Asset statuses:
  - **Available**: In studio, ready for use
  - **In Use**: Deployed at off-site event/booth
  - **Maintenance**: Under repair/servicing
- Overview table + View button → shows generated QR
- **Scan QR button**: physical-digital connection
  - Instant access to current data
  - Quick status/location/condition updates
  - Field-ready, real-time updates
- Download Excel:
  - Filter by category, status, etc.
  - Ask SnapFunny for custom exports (specific columns)

---

## E. Inventory (2 minutes)

**[Screen: Inventory menu]**

- Inventory = consumable supplies (paper, backdrops, props, cables)
- Critical: prevent stockouts during events
- Filter options: In Stock, Low Stock, No Stock
- Demo: Create new inventory item
- **Business rule**: New items may not be purchased yet
  - Leave Stock Quantity + Vendor blank
  - Auto-fill when procurement completed
  - Ensures data consistency
- **UoM + Vendor validation**:
  - Must come from master data
  - No arbitrary values
  - Add new via dedicated buttons
  - Maintains data integrity
- **Low Stock Alert - Restock Needed** card:
  - Auto-identifies low/no stock items
  - One place visibility
  - **Auto Draft button**: Creates draft PR automatically
  - Streamlines restocking, reduces manual work

---

## F. Events & Booths (2 minutes)

**[Screen: Events & Booths menu]**

- Events & Booths = business operations heart
- Manages: in-studio services + off-site booth bookings
- Timeline view by status: Upcoming, In Progress, Completed, Cancelled
- Resource planning + capacity management
- Demo: Create new event
- **Business rule 1 - Customer field**:
  - Must select from registered customers
  - No arbitrary names
  - Links events to customer records
- **Business rule 2 - Assets + conflict detection**:
  - Asset assigned to Event A (time period)
  - Event B tries same asset (same time, qty=1)
  - System rejects + alerts: asset unavailable
  - Prevents double-booking, operational conflicts
- **Automatic status update**:
  - Event → In Progress
  - Assigned assets → In Use (automatic)
  - Assets module reflects current reality

## H. Procurement (2 minutes)

**[Screen: Procurement menu]**

- Procurement = supply chain management
- Purchases: new assets + consumable supplies
- Demo: Add New Request (create PR)
- **Classification step**: Supplies vs. Assets
  - System retrieves correct master data
  - Applies appropriate workflows
- **Item selection validation**:
  - No arbitrary names
  - Retrieves from master data
  - Maintains data integrity
- **Approval workflow**:
  - PR submitted
  - Admin with purchasing authority reviews
  - Approved → becomes PO (Purchase Order)
  - Purchasing staff proceeds with vendor
- **Quality inspection on arrival**:
  - Items arrive → SnapFun inspects
  - Pass specs → Admin clicks "Received"
  - Inventory auto-updated
  - Fail inspection → Admin rejects + documents reason
  - Quality control record + follow-up triggers
- End-to-end: accountability, quality control, seamless inventory updates

---

## I. Customers (1.5 minutes)

**[Screen: Customers menu]**

- Customers = client relationship management
- Two segments:
  - **In Studio**: walk-in customers
  - **Off Site**: event/booth bookings
- Add new customer → fill details
- Assign to appropriate segment
- **In Studio process**:
  - Customer visits for services
  - Create transaction record
  - Select in-studio package
  - Records service delivery + revenue
- **Off Site process**:
  - Customer books SnapFun for events/booths
  - Assign to Off Site segment
  - Name available in Events & Booths (Customer field)
- **Revenue tracking** (top of screen):
  - In Studio revenue
  - Off Site revenue
  - Performance analysis by service line
- **Accounting Report button**:
  - Transaction recaps
  - Customer activities OR procurement purchasing
  - Financial analysis + reporting
- **Manage Promo & Discount**:
  - Promotion master data
  - Activate promo codes
  - Apply to: in-studio transactions OR off-site events
  - Optional usage
  - Pricing strategy flexibility
